\subsection{Parellization using MPI}
The parellel implementation of the $\pi$ computation is based on the idea of dividing the interval $[0, 1]$ into $N$ subintervals, where $N$ is the number of processes. Each process computes the contribution to $\pi$ from its assigned subinterval and then all contributions are summed together using MPI. In listing \ref{lst:pi_mpi} we show the implementation of the parallel $\pi$ computation using MPI.

\begin{lstlisting}[style=grayverbatim, caption={Parallel $\pi$ computation using MPI}, label={lst:pi_mpi}]
MPI_Init(&argc, &argv);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
MPI_Comm_size(MPI_COMM_WORLD, &size);

h = 1.0 / (double)N;

MPI_Barrier(MPI_COMM_WORLD);
time_start = walltime();

for (uint64_t i = (uint64_t)rank; i < N; i += (uint64_t)size) {
    double x = (i + 0.5) * h;
    local_sum += 4.0 / (1.0 + x * x);
}

MPI_Reduce(&local_sum, &sum, 1, MPI_DOUBLE, MPI_SUM, 0, MPI_COMM_WORLD);
double time = walltime() - time_start;
if (rank == 0) {
    pi = sum * h;
    printf("# pi N procs time [secs]\n");
    printf("%.15f %20" PRIu64 " %3d %.8f\n", pi, N, size, time);
    }

MPI_Finalize();
\end{lstlisting}
Each process starts from its rank and iterates over the indices of the subintervals assigned to it by incrementing the index by the total number of processes in each iteration. This way, each process computes the contribution to $\pi$ from its assigned subintervals without overlap. After the local sums are computed, they are reduced to a single sum using \texttt{MPI\_Reduce}, which is then used to compute the final value of $\pi$ on the root process (rank 0).

\section{Ring sum using MPI [10 points]}
In listing \ref{lst:ring_sum} we show the implementation of the ring sum using MPI.
\begin{lstlisting}[style=grayverbatim, caption={Ring sum using MPI}, label={lst:ring_sum}]
int size, rank;
MPI_Init(&argc, &argv);
MPI_Comm_size(MPI_COMM_WORLD, &size);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);

// IMPLEMENT: Ring sum algorithm
int sum = rank;
for (int i = 0; i < size - 1; i++) {
  int send_to = (rank + 1) % size;
  int recv_from = (rank - 1 + size) % size;

  int recv_sum;
  MPI_Sendrecv(&sum, 1, MPI_INT, send_to, 0,
              &recv_sum, 1, MPI_INT, recv_from, 0,
              MPI_COMM_WORLD, MPI_STATUS_IGNORE);

  sum += recv_sum;
}
printf("Process %i: Sum = %i\n", rank, sum);

// Finalize MPI
MPI_Finalize();
\end{lstlisting}

The implementation uses a \textbf{ring communication pattern}, where each process exchanges data only with its immediate neighbors in a cyclic topology. Specifically, process $i$ sends its current partial sum to process $(i+1) \bmod P$ and receives a value from process $(i-1 + P) \bmod P$, where $P$ is the total number of processes.\\

Each process initializes its local sum with its rank and performs $P-1$ communication steps. At every iteration, it forwards its current partial sum to the next process and accumulates the value received from the previous one. This ensures that, after all iterations, every process has received contributions from all other processes and therefore holds the global sum.\\

To avoid deadlock issues, the implementation uses the \texttt{MPI\_Sendrecv} routine instead of separate blocking send and receive calls. This function performs the send and receive operations in a single, coordinated step, ensuring that communication progresses safely without requiring explicit ordering between processes.
