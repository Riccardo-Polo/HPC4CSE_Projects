From listing \ref{lst:deviceQuery} we can derive that:
\begin{itemize}
  \item The number of Streaming Multiprocessors (SMs) is $n_{\text{SMs}} = 68$
  \item The number of CUDA cores per SM is $n_{\text{cores per SM}} = 64$ 
  \item The GPU maximumclock frequency is $f = 1.545$ GHz
  \item  The CUDA Compute Capability is $7.5$
\end{itemize}

From \cite{hpc_cuda_best_practices_guide} we can derive the following information about the number of floating point operations per FMA.
\begin{itemize}
  \item For single precision (FP32) FMAs $TP_{\text{FP32}}=\frac{64}{64}=1$
  \item For double precision (FP64) FMAs $TP_{\text{FP64}}=\frac{64}{2}=32$
\end{itemize}
Thus we can compute the theoretical peak performance of an NVIDIA GeForce RTX 2080 Ti for single and double precision as:
\begin{align*}
  P_{\text{FP32}} &= n_{\text{SMs}} \cdot \frac{n_{\text{cores per SM}}}{TP_{\text{FP32}}} \cdot n_{FMA} \cdot f\\ &= 68 \cdot \frac{64}{1} \cdot 2 \text{FP32} \cdot 1.545 \text{GHz} = 13450,56 \text{ GFLOPS} \\
  P_{\text{FP64}} &= n_{\text{SMs}} \cdot \frac{n_{\text{cores per SM}}}{TP_{\text{FP64}}} \cdot n_{FMA} \cdot f \\ &= 68 \cdot \frac{64}{32} \cdot 2 \text{FP64} \cdot 1.545 \text{GHz} = 420,33  \text{ GFLOPS}
\end{align*}

From Listing \ref{lst:deviceQuery} we can get the following informations
\begin{itemize}
  \item Global Memory : $10821$ MiB $ =10.57 $ GiB
  \item L2 Cache Size: $5.5$ MiB
  \item L1 and Shared Memory per SM 96 KiB 
  \item Read only memory $64$ KiB
  \item Registers $64$ Ki registers per block, each holding $4$ bytes (total $256$ KiB).
  \item Memory bus width: $W_{\text{mem}} = 352$ bits
  \item Memory clock frequency: $f_{\text{mem}} = 7$ GHz
\end{itemize}
So we can compute the (theoretical) peak memory bandwidth of a GPU as:
\begin{align*}
  B_{\text{GPU}} &= \frac{W_{\text{mem}}}{8} \cdot f_{\text{mem}} \cdot 2\\
  &= \frac{352}{8} \cdot 7 \text{GHz} \cdot 2 = 616 \text{ GB/s}
\end{align*}

\subsection{Performance model: A simple roofline model [5 Points]}
Compute ridge points
$$ I_{\text{ridge}} = \frac{P_{\text{peak}}}{B_{\text{GPU}}}$$
For single precision:
$$ I_{\text{ridge, FP32}} = \frac{13450.56 \text{ GFLOPS}}{616 \text{ GB/s}} = 21.83 \text{ GLOP/byte}$$
For double precision:
$$ I_{\text{ridge, FP64}} = \frac{420.33 \text{ GFLOPS}}{616 \text{ GB/s}} = 0.68 \text{ GLOP/byte}$$

We can retrieve a roofline plot for the NVIDIA GeForce RTX 2080 Ti remembering that $P_{\text{attainable}} = \min{P_{\text{peak}}, B_{\text{GPU}} \cdot I_{\text{ridge}}}$.\\
In figure \ref{fig:roofline} we can see the roofline plot for the NVIDIA GeForce RTX 2080 Ti for single and double precision.
\begin{figure}[!h]
  \centering
  \includegraphics[width=0.8\textwidth]{../01_performance/roofline_fp32_fp64.pdf}
  \caption{Roofline plot for the NVIDIA GeForce RTX 2080 Ti for single and double precision.}
  \label{fig:roofline}
\end{figure}

Thus, when the operational intensity of a kernel is lower than $I_{\text{ridge}}$ the kernel is memory bound, otherwise it is compute bound.
\section{Introduction to CUDA [50 Points]}

\subsection{Implement the simple kernels [30 Points]}
The CUDA implementation of the functions in the file \texttt{simple\_kernels.cu} is straightforward and it is based on the standard CUDA programming model. For everty function we first computed the correct index as \texttt{int i = blockIdx.x * blockDim.x + threadIdx.x} and then we check if the index is within the bounds of the input vectors by \texttt{if ( i < N )}. If the index is valid we perform the corresponding operation on the input vectors and we store the result in the output vector.\\
In this case, since in the \texttt{benchmark.cu} file the number of blocks is computed as 
\texttt{int blocks = (SIZE + threads - 1) / threads} and the number of threads per block is set to $256$, we do not need in principle to worrry about the number of threads and blocks, since the kernel will be launched with enough threads to cover all the elements of the input vectors. However, we need to check if the index is within the bounds of the input vectors to avoid out-of-bounds memory accesses.\\

\subsection{Implement the scalar product kernel [20 Points]}
The CUDA implementation of the scalar product kernel is based on the use of \texttt{atomicAdd} to perform the reduction of the partial sums computed by each thread. Each thread computes a partial sum of the scalar product for a subset of the input vectors and then uses \texttt{atomicAdd} to add its partial sum to a global variable that holds the final result.\\
The implementation of the kernel is reported in listing \ref{lst:scalar_product_kernel}.
\begin{lstlisting}[style=grayverbatim,caption={CUDA kernel for the scalar product.},language=C++,label={lst:scalar_product_kernel}]
int i = blockIdx.x * blockDim.x + threadIdx.x;
int stride = blockDim.x * gridDim.x;
for (; i < N; i += stride) {
    atomicAdd(result, x[i] * y[i]);
}
\end{lstlisting}
In this case we had to introduce a variable \texttt{stride} to allow each thread to compute the scalar product for a subset of the input vectors, since the number of threads launched by the kernel is not necessarily equal to the size of the input vectors. This is because the program is launched with a fixed number of threads per block and a fixed number of blocks (respectively $256$ and $7*68$), thus we need to allow each thread to compute the scalar product for multiple elements of the input vectors.\\

\section{Non-linear PDE mini-app with CUDA: The Fisher equation [35 Points]}
The linear algebra kernels were implemented using the same approach as for the simple kernels, thus we do not report the implementation of the kernels in this report.\\

The implementation of the stencil operator for the finite difference discretization is reported in listing \ref{lst:stencil_operator}. The implementation of the kernel is based on the standard CUDA programming model, where each thread computes the value of the stencil operator for a single point in the grid. The kernel takes as input the old and new solution vectors, the right-hand side vector, the parameters $\alpha$ and $\beta$, the boundary conditions and the size of the grid. The kernel computes the value of the stencil operator for each point in the grid, taking into account the boundary conditions for the points on the boundaries of the grid.\\
\begin{lstlisting}[style=grayverbatim,caption={CUDA kernel for the stencil operator.},language=C++,label={lst:stencil_operator}]
__global__ void diffusion(real_t* const s_old,
               real_t* const s_new,
               real_t* f,
               real_t alpha,
               real_t beta,
               real_t* const bndE,
               real_t* const bndW,
               real_t* const bndN,
               real_t* const bndS,
               int nx) {
    
    int iend = nx-1;
    int jend = nx-1;

    int i = blockIdx.x * blockDim.x + threadIdx.x;
    int j = blockIdx.y * blockDim.y + threadIdx.y;
    int idx = i + j * nx;

    if (i > 0 && i < iend && j > 0 && j < jend) {
        // interior points
        f[idx] = -(4+alpha)*s_new[idx]
                        + s_new[idx-1] + s_new[idx+1]
                        + s_new[idx-nx] + s_new[idx+nx]
                        + beta*s_new[idx]*(1-s_new[idx])
                        + alpha*s_old[idx];
    }

    else if (i==iend && j > 0 && j < jend) {
        // east interior boundary
        f[idx] = -(4+alpha)*s_new[idx]
                        + s_new[idx-1] + bndE[j]
                        + s_new[idx-nx] + s_new[idx+nx]
                        + beta*s_new[idx]*(1-s_new[idx])
                        + alpha*s_old[idx];
    }
    
    else if (i==1 && j > 0 && j < jend) {
        // west interior boundary
        f[idx] = -(4+alpha)*s_new[idx]
                    + bndW[j] + s_new[idx+1]
                    + s_new[idx-nx] + s_new[idx+nx]
                    + beta*s_new[idx]*(1-s_new[idx])
                    + alpha*s_old[idx];
    }

    else if(j==jend && i > 0 && i < iend) {
        // north interior boundary
        f[idx] = -(4+alpha)*s_new[idx]
                        + s_new[idx-1] + s_new[idx+1]
                        + s_new[idx-nx] + bndN[i]
                        + beta*s_new[idx]*(1-s_new[idx])
                        + alpha*s_old[idx];
    }

    else if(j==1 && i > 0 && i < iend) {
        // south interior boundary
        f[idx] = -(4+alpha)*s_new[idx]
                    + s_new[idx-1] + s_new[idx+1]
                    + bndS[i] + s_new[idx+nx]
                    + beta*s_new[idx]*(1-s_new[idx])
                    + alpha*s_old[idx];
    }

    else if (i==iend && j==jend) {
        // NE corner
        f[idx] = -(4+alpha)*s_new[idx]
                    + s_new[idx-1] + bndE[j]
                    + s_new[idx-nx] + bndN[i]
                    + beta*s_new[idx]*(1-s_new[idx])
                    + alpha*s_old[idx];
    }
    
    else if (i==1 && j==jend) {
        // NW corner
        f[idx] = -(4+alpha)*s_new[idx]
                + 0.1 + s_new[idx+1]
                + s_new[idx-nx] + bndN[i]
                + beta*s_new[idx]*(1-s_new[idx])
                + alpha*s_old[idx];
    }

    else if(i == iend && j == 1) {
        // SE corner
        f[idx] = -(4+alpha)*s_new[idx]
                + s_new[idx-1] + bndE[j]
                + 0.1 + s_new[idx+nx]
                + beta*s_new[idx]*(1-s_new[idx])
                + alpha*s_old[idx];
    }

    else if(i == 1 && j == 1) {
    // SW corner
    f[idx] = -(4+alpha)*s_new[idx]
        + bndW[j] + s_new[idx+1]
        + bndS[i] + s_new[idx+nx]
        + beta*s_new[idx]*(1-s_new[idx])
        + alpha*s_old[idx];
    }
}
\end{lstlisting}
